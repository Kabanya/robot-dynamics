Whole-Body Physics Signatures for Humanoid Gait Failure Ranking

Minimum requirements

- A 64-bit Linux or macOS system with Conda.
- Python 3.12.3 and the exact packages in conda-explicit.txt and
  pip-requirements.txt. The tested platform is Apple Silicon macOS 26.5.2.
- Sufficient memory and CPU time for Pinocchio whole-body rollouts.
- Any standard H.264/MP4 player for rollout_examples.mp4. The submitted file
  was encoded with FFmpeg 8.1.1 and verified with ffprobe.

Usage

README.md gives the commands for checking the archived result, regenerating
the two manuscript figures, and optionally repeating the two 400-rollout
confirmations. Repeating simulation is not required to inspect the CSV, JSON,
figures, or video.
